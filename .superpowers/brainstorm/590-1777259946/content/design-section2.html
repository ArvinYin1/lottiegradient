设计文档 — 第二部分：数据模型与交互

面板位置状态、拖拽逻辑、连线计算

面板状态数据结构

const panelState = {
  preview:   { x: 40,  y: 60,  w: 400, h: 420 },
  list:      { x: 500, y: 80,  w: 280, h: 360 },
  editor:    { x: 820, y: 60,  w: 320, h: 400 }
};

// 面板之间的固定连接关系
const connections = [
  { from: 'preview', to: 'list' },
  { from: 'list',    to: 'editor' }
];

每个面板的位置和尺寸存储在内存中，不持久化到 localStorage（每次刷新重置为默认布局）。

拖拽交互逻辑

  • mousedown on 标题栏：记录起始鼠标位置和面板当前位置，添加 cursor: grabbing
  • mousemove：计算偏移量 Δx/Δy，更新面板 transform: translate(newX, newY)，同步重绘 SVG 连线
  • mouseup：移除事件监听，恢复 cursor: grab
  • 拖拽时面板提升 z-index 到最上层，避免被其他面板遮挡

调整大小交互逻辑

  • mousedown on 右下角手柄：记录起始鼠标位置和面板当前宽高
  • mousemove：计算新宽高（最小 200×150px），更新面板 width/height 样式，同步重绘 SVG 连线
  • mouseup：移除事件监听

贝塞尔连线计算

// 从面板 A 右侧中点 → 面板 B 左侧中点
function getConnectionPath(panelA, panelB) {
  const startX = panelA.x + panelA.w;  // A 的右边缘
  const startY = panelA.y + panelA.h / 2;  // A 的垂直中点
  const endX   = panelB.x;             // B 的左边缘
  const endY   = panelB.y + panelB.h / 2;  // B 的垂直中点

  // 控制点：水平延伸，创造平滑曲线
  const controlOffset = Math.abs(endX - startX) * 0.5;
  const cp1x = startX + controlOffset;
  const cp1y = startY;
  const cp2x = endX - controlOffset;
  const cp2y = endY;

  return `M ${startX} ${startY} C ${cp1x} ${cp1y}, ${cp2x} ${cp2y}, ${endX} ${endY}`;
}
