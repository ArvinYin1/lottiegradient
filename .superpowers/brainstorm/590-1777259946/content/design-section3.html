与现有代码的整合策略

  • DOM ID 保持不变：#lottie-animation、#gradient-names-list、#editor 等 ID 不变，确保 JS 逻辑无需修改
  • 面板内容完全复用：将现有的 #preview-card、gradient-list-panel、editor-panel 的内容迁移到新的 canvas-panel 结构中
  • 拖拽/调整大小逻辑独立封装：新建 CanvasWorkspace 类，负责面板位置管理、拖拽、连线绘制，与业务逻辑解耦
  • CSS 独立维护：画布相关的样式（.canvas-panel、.panel-header 等）放在 style.css 中新增一个区块

事件处理细节

  • 拖拽时阻止文本选中：e.preventDefault() + user-select: none，避免拖拽过程中误选文本
  • 边界约束：面板不能拖出画布可视区域（保留至少 40px 可见）
  • 最小尺寸：宽度 ≥ 200px，高度 ≥ 150px
  • 窗口 resize：监听 window resize，如果面板超出新窗口范围，自动将其移回可视区域
